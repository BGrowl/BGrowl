# BGrowl

南方科技大学在读学生。主要做嵌入式控制、信号处理和 Python 自动化。

### 技术栈

| 方向 | 技术与方法 |
| --- | --- |
| 编程语言 | C / C++、Python、JavaScript |
| 嵌入式与控制 | STM32 HAL、Arduino、MPU6050、编码器、PD / PI 控制、串口通信、任务状态机 |
| 信号处理与可视化 | MAX30102、PPG、心率 / HRV 估计、灌注指数、信号质量判定、PyQt6、pyqtgraph |
| 数据与 Web | 数据采集、规格归一化、评分与筛选、HTML / CSS / JavaScript、消息推送 |
| 工具与部署 | Git、GitHub Actions、Linux、回归测试、诊断日志、LaTeX |

### 项目经验

- **[嵌入式控制与视觉联调](https://github.com/BGrowl/STM32F767-balance-car)**：STM32F767 双轮平衡控制，结合 K230 完成红球识别、搜索、对准与推球；涉及姿态解算、控制参数调试、模块通信和任务状态机。
- **[生理信号处理](https://github.com/BGrowl/ST_Project)**：MAX30102 指尖 PPG 监测原型，包含心率、短时 HRV 估计、灌注指数、四态信号质量判定和 PyQt6 实时波形界面。
- **[数据处理与前端优化](https://github.com/BGrowl/kaquan-bijia)**：跨商家规格归一化与比价，数据快照覆盖 38 家商家、6,180 个规格；实现商品直链、移动端加载优化与定时自动发布。
- **[Python 应用开发](https://github.com/BGrowl/zuche-hitch-board)**：使用标准库构建车源采集、评分、筛选、网页看板和微信通知，包含后台刷新、通知去重与失败恢复。
- **[Android 自动化实验](https://github.com/BGrowl/shangou-android)**：手机端独立运行、时间校准、定时触控与诊断，保留 63 项回归测试；目前暂时搁置。
