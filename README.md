**[ST_Project](https://github.com/BGrowl/ST_Project)** · 指尖外周循环监测系统
基于 MAX30102 的 PPG 原型：Arduino 侧做峰值检测、PPI、心率、短时 HRV 与灌注指数（PI），Python/PyQt6 上位机做实时波形与数值展示。重点不在「多一个心率数字」，而是把 **信号质量做成四态机**（Checking / Weak Signal / Motion / Good），让不可靠的测量自己说出来。含一篇 IEEE 会议格式论文。
